## 已定口径（PRD v1.20 + task 035 实测，无需再拍板）

- **窗口** = JA 旋转日历 GHI 段 2025-01-24~2026-01-22 含过渡期（`config/tournament_envs.yml` 既有 JP 段，env 推导复用 `normalize/envs.py`）。
- **入选依据** = 聚合站收录的上位卡组码（FR-9.5）；官方赛事范围 = PJCS / チャンピオンズリーグ（CL）/ シティリーグ（City League）；ジムバトル等小店赛拒收（FR-9.1a 质量筛选）。
- **deck confirm 采集纪律**：5s/请求 + 熔断 + 逐码断点续传 + 请求台账；**采集前先出请求量估算，超闸门（默认 500）降级只收 PJCS/CL**。
- **卡表解析**：confirm 页静态 HTML 内嵌（task 035 推翻性发现②）——hidden input `deck_pke/gds/tool/tech/sup/sta/ene/ajs` + `PCGDECK.searchItemName[cardId]`，纯正则零 JS；卡名归一复用 `normalize_ja_deck_name`（ACE SPEC 后缀剥离）。
- **映射**：JA 名 → `cards.name_ja`（task 036 水位：GHI distinct 名覆盖 84.8%，演练 5/5 full）；未映射落 `deck_card_misses`（miss_kind=no_cn_printing 等，复用 task 032 钩子，不猜）；mapping_status full/partial 单调口径同既有通道。
- **入库口径**：record 三列 NULL 不猜（聚合站无比分）；topcut_slots = 收录名次数物化；division 未知不排他；pairings 无（聚合站不提供逐桌）。
- **隐私最小化**：player_ref 只存官方选手编号（pinCode），不存昵称。
- **对账**：players 壳源 Cloudflare 403 不可用 → 聚合站两站互核（pokecabook × pokecardlab 壳数据场次/名次/archetype 比对）。
