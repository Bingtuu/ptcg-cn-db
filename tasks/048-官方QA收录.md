## 供给端调研结论（2026-08-28 实地调研）

**立项前提「简中官网 Q&A 页」实测不存在**：

- `/tcg-rules` 枢纽页只有 howtoplay + regulation 两个子页；`/tcg/qa`、`/tcg/faq`、`/support` 等候选 URL 全 404；官网导航（首页 / tcg-home / tcg-rules）无 Q&A 入口；WordPress REST API 登录门控（401 rest_login_required）
- 卡级 Q&A 只在「宝可梦卡牌会员」小程序内（D1 已否决抓包路线，PRD 第 14 章）
- mik.moe card-detail 本地 raw 逐键确认无 Q&A 字段（data 键仅 name/cardType/mechanic/label/description/yorenCode/pokemonAttr/setCode/cardIndex/setCardsNum/artist/rarity/releaseDate/regulationMark/effectId/regulationLegal/effectSameCards/setCodeEn/cardIndexEn/nameEn）
- JP 官方每卡 Q&A（pokemon-card.com）存在但 WAF 严格，现行红线只允许 ≤35 请求抽样（FR-9.5 例外仅覆盖 deck/confirm），批量需新一轮拍板

**发现的替代供给**（如未来重启，优先此路）：官网「补充说明」类公告文章是事实上的简中官方卡级裁决载体——如「利刃猛醒」收录部分卡牌的补充说明（/tcg/other/20058.html，铁荆棘 CSV7C 090/204）、有关【气球】和【球果匠人】的说明（/tcg/other/17182.html）。文章级、带卡号/卡名可机读关联 card_id，且在 L1 新闻监控 + task 047 勘误草稿 loop 覆盖范围内；历史文章（基线前）需回扫 /category/tcg 全 78 页列表筛标题补齐。重启时按此改任务范围（公告文章收录 + 卡级关联，新表 card_notices 之类），预估量级 10~30 篇。
